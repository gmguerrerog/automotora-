# KR Automóviles · Landing page

Página estática (un solo `index.html`, sin dependencias). Abrir en el navegador o subir la carpeta a cualquier hosting (GitHub Pages, Netlify, Vercel).

- Logo, fotos de autos y del local: recortados de capturas del Instagram @krautomoviles.cl (`img/`).
- WhatsApp: usa el link de la bio (`wa.me/message/EPWVZZKXUJV5G1`).

## Para mejorar
1. **Número de WhatsApp**: si se pone en `CONFIG.whatsapp`, los botones abren el chat con el mensaje ya escrito (con el link de la bio no se puede pre-escribir).
2. **Catálogo** (arreglo `AUTOS` en `index.html`): agregar `anio`, `km` y `precio` a cada auto. Sin precio se muestra "Consultar".
3. **Fotos en alta**: reemplazar las imágenes de `img/autos/` por originales en mejor calidad (mismo nombre de archivo).
4. **Logo en alta**: reemplazar `img/logo.png` por el archivo original.
